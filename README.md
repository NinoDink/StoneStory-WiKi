# StoneStory Wiki

Atividade do curso **UniSenai**.

O projeto consiste na criação de um site utilizando o suporte da **AWS**, tendo como tema escolhido o jogo **Stone Story RPG**.

A proposta é desenvolver uma **Wiki dedicada ao jogo**, reunindo informações sobre seus elementos, como personagens, inimigos, equipamentos, itens, áreas, mecânicas e outros conteúdos relacionados ao universo de *Stone Story RPG*.

## 🎮 Sobre o projeto

O **StoneStory Wiki** tem como objetivo centralizar informações do jogo em um único lugar, facilitando a consulta e a exploração de seu conteúdo pelos jogadores.

O projeto também serve como atividade prática para aplicação dos conhecimentos adquiridos durante o curso, envolvendo desenvolvimento web, organização de informações e utilização de serviços da AWS.

## 🛠️ Tecnologias

* HTML
* CSS
* JavaScript
* AWS

## 📚 Objetivos

* Criar uma Wiki funcional sobre *Stone Story RPG*;
* Organizar as informações do jogo de maneira clara;
* Desenvolver uma interface simples e intuitiva;
* Praticar os conhecimentos adquiridos no curso;
* Utilizar recursos da AWS durante o desenvolvimento e hospedagem do projeto.
